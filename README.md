# Mobile Application Development

This repository contains projects developed for the **Mobile Application Development** course at Ho Chi Minh City University of Technology and Education (HCMUTE).

The projects cover Android development, Firebase, IoT integration, artificial intelligence, computer vision, embedded systems, and client-server communication.

---

## Projects

### 01. HCM-UTE Smart Access

A smart classroom access management system that integrates an Android application with Firebase and IoT devices.

The system supports multiple authentication methods and classroom access management features.

**Technologies:**

- Kotlin
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore
- ESP32
- NFC / RFID
- Fingerprint Sensor
- Servo Motor

**Main Features:**

- Student and administrator authentication
- Student registration and approval
- NFC-based authentication
- Fingerprint authentication
- Classroom access control
- Attendance management
- Access logging
- Real-time data synchronization with Firebase

➡️ [View HCM-UTE Smart Access](./01_HCMUTE_Smart_Access)

---

### 02. Advanced AI Project

An AI-based computer vision project covering the complete workflow from model training and evaluation to deployment and client-server communication.

The project includes AI model training on Kaggle, model export and compatibility processing, deployment on a BeagleBone Black device, and communication with a laptop client.

**Technologies:**

- Python
- Artificial Intelligence
- Computer Vision
- OpenCV
- ONNX
- Kaggle
- BeagleBone Black
- Linux
- TCP/IP Networking

**Project Workflow:**

```text
Dataset
   ↓
Model Training
   ↓
Model Evaluation
   ↓
Model Export
   ↓
Model Deployment
   ↓
BeagleBone Black Server
   ↕
Laptop Client
```

➡️ [View Advanced AI Project](./02_AI_Advanced_Project)
